# Tuma

Bulk SMS for Kenyan businesses: a marketing page and an app for uploading a CSV and sending personalised messages. See `docs/PLAN.md`.

Create `.env.local`:

```
APP_PASSWORD=
AUTH_SECRET=at-least-32-random-characters
```

Then `npm run dev`. With no supplier set, the app runs in demo mode and sends nothing. The supplier settings are listed in the plan.
